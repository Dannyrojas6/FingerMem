# Basic 850 Cognitive — 认知科学驱动的英语学习词典

基于 Charles K. Ogden 的 **Basic English 850 词**，结合认知科学原则设计的三阶段递进式英语学习词典。

## 结构

```
basic-850-cognitive/
├── scenes/                  ← 53 个场景 JSON（应用只同步此目录）
├── word-index.json          ← 850 词覆盖率索引（不同步到应用）
└── README.md
```

## 三阶段递进

| 阶段 | 组数 | 内容 | 语法 |
|:----:|:----:|------|------|
| Phase 1 | 10 | 操作词（动词/介词/连词/副词 ~150词） | 简单现在时+肯定 |
| Phase 2 | 31 | 名词+形容词（自我→家→社区→世界 ~600词） | 逐步引入否定/疑问/进行时 |
| Phase 3 | 12 | 跨场景叙事+查漏补缺 | 过去时/完成时/比较级 |

## 句子设计六原则

1. **词汇锚定** — 新词在组内复现
2. **语法递进** — 从简单到复杂
3. **情景嵌入** — 句子可想象场景
4. **组内连贯** — 微叙事/微对话
5. **跨组回访** — 后期引用前期词汇
6. **自然度优先** — 不牺牲地道表达

## 数据格式

```json
{
  "name": "主题名称",
  "sentences": [
    { "en": "English sentence.", "zh": "中文翻译。" }
  ]
}
```
